# Number Hunt

A small terminal guessing game written in Python. Pick a difficulty, guess a
number from 1 to 100, and see if you can find it before you run out of tries.

## Run

```bash
python3 guessing_game.py
```

Easy gives you 10 guesses, Medium gives you 7, and Hard gives you 5. Enter
`y` to play another round or `n` to quit and see your score.
